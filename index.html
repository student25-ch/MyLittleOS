MyLittleOS

A 32-bit x86 hobby operating system

Features

  • VGA text buffer output
  • PS/2 Keyboard scan code reader
  • PS/2 Mouse initialization
  • RTL8139 network driver placeholder
  • Freestanding bare-metal, no libc / C++ standard library

Source Code

All source code released under MIT License.

Compiled binaries (kernel.elf, *.o) are kept locally by developer, not uploaded.

Build Environment

  • Windows
  • i686-elf cross compiler
  • NASM assembler
  • QEMU (for testing)

Build Guide

1. Enter src folder

2. Run build.bat

3. Output: kernel.elf
